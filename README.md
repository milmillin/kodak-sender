# Kodak Sender (web app)

Print photos to a Kodak Instant printer over Web Bluetooth. This is the production version of
[`../send.html`](../send.html): a React + Vite PWA that runs on desktop Chrome/Edge and Android Chrome.
iOS Safari has no Web Bluetooth (the Bluefy browser does).

```sh
npm install
npm run dev        # http://localhost:5173 (localhost counts as a secure context)
npm test           # parity tests against send.html + protocol tests
npm run build      # → dist/, deployable to any static host
```

## Layout

- `src/pipeline/`: the print pipeline, ported line for line from `send.html` (resize & crop,
  sharpen, 3D/1D LUTs, thermal-head comp, JPEG). `src/__tests__/parity.test.ts` loads the original
  functions out of `send.html` and asserts byte-identical output, so keep the two in sync.
- `src/worker/`: runs the pipeline off the main thread.
- `src/ble/`: GATT protocol (`protocol.ts`, see `docs/ble-status.md`) and the connection/transfer
  loop (`printer.ts`).
- `src/pipeline/lut.json`: generated by `npm run extract-lut` from `send.html`.
- `public/` icons: generated by `node scripts/make-icons.mjs`.

## Deploy

`.github/workflows/pages.yml` tests, builds and publishes `dist/` on every push to `main` that touches
`web/`. One-time setup: **Settings → Pages → Source: GitHub Actions**.
