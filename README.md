# Kodak Sender (web app)

Print photos to a Kodak Instant printer over Web Bluetooth: a React + Vite PWA that runs on desktop
Chrome/Edge and Android Chrome. It grew out of a single-file prototype, kept as
[`reference/send.html`](reference/send.html).
iOS Safari has no Web Bluetooth (the Bluefy browser does).

```sh
npm install
npm run dev        # http://localhost:5173 (localhost counts as a secure context)
npm test           # parity tests against reference/send.html + protocol tests
npm run build      # → dist/, deployable to any static host
```

## Layout

- `src/pipeline/`: the print pipeline, ported line for line from `reference/send.html` (resize & crop,
  sharpen, 3D/1D LUTs, thermal-head comp, JPEG). `src/__tests__/parity.test.ts` loads the original
  functions out of `reference/send.html` and asserts byte-identical output, so keep the two in sync.
- `src/worker/`: runs the pipeline off the main thread.
- `src/ble/`: GATT protocol (`protocol.ts`, see `docs/ble-status.md`) and the connection/transfer
  loop (`printer.ts`).
- `src/pipeline/lut.json`: generated by `npm run extract-lut` from `reference/send.html`.
- `public/` icons: generated by `node scripts/make-icons.mjs`.

## Deploy

`.github/workflows/pages.yml` tests, builds and publishes `dist/` on every push to `main`.
One-time setup: **Settings → Pages → Source: GitHub Actions**.
